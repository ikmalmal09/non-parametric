When to Use Each Test?

Quick reference guide for choosing the right non-parametric test.

Sign Test

Use when you want to test a median against a value and only the direction of deviation matters. Robust but low power.

One sample Ordinal OK Minimal assumptions
binom.test(n_plus, n, p=0.5)

Wilcoxon Signed-Rank

Use when data are continuous and symmetric, for one-sample or paired before/after designs. More powerful than the sign test.

One sample / Paired Symmetric dist.
wilcox.test(x, mu=0) wilcox.test(before, after, paired=TRUE)

Mann-Whitney U

Use to compare two independent groups without assuming normality. Tests whether one group tends to have larger values than the other.

Two independent groups No normality needed
wilcox.test(g1, g2, paired=FALSE)

Kruskal-Wallis

Use for three or more independent groups. If significant, follow with Dunn's post-hoc test to identify which pairs differ.

3+ groups Independent Post-hoc: Dunn's
kruskal.test(list(g1, g2, g3))

Spearman ρ

Use when the relationship between two variables is monotonic but not necessarily linear, or when data contain outliers.

Correlation Monotonic Outlier-robust
cor.test(x, y, method="spearman")

Quick Decision Guide

  • →One sample vs. median? Sign test or Wilcoxon signed-rank
  • →Two independent groups? Mann-Whitney U
  • →Three or more groups? Kruskal-Wallis
  • →Paired / repeated measures? Wilcoxon signed-rank
  • →Monotonic association? Spearman ρ
  • →Unsure of normality? Use any of the above
